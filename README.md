# todolist

用于记录暂未决定实施、但值得后续继续调查或实现的项目想法、架构方案与功能计划。

## 使用方式

主要通过 GitHub Issues 记录待考虑事项。每个 Issue 尽量包含背景、目标、初步方案、需要进一步调查的问题以及当前状态。

这里的内容默认表示 **候选方案 / TODO / Idea**，不代表已经进入正式开发计划。

## 当前方向

- RelaxKonOS 及其生态扩展
- Remote Workspace / Remote Development
- IDE 与编辑器集成
- Agent / AI 开发工具集成
- 其他值得后续尝试的项目与技术方案
